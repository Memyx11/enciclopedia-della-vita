## ⚠️ CODICE ATECO — LA DOMANDA CRITICA

### Il tuo dubbio è GIUSTO

Le tue entrate derivano da **abbonamenti per usare NUR**. Questo è tecnicamente un **SaaS (Software as a Service)**.

### Il problema

| Codice | Tipo | INPS | Contributi |
|--------|------|------|------------|
| 62.01.02 / 62.10.00 | Sviluppo software | Gestione Separata | **Solo % su reddito** (€0 se non fatturi) |
| 63.10.10 (ex 63.11.30) | Hosting/SaaS | Commercianti | **~€4.500/anno FISSI** anche con €0 fatturato |

### La verità

**Se vendi abbonamenti per usare un software = tecnicamente attività commerciale = 63.10.10 = €4.500/anno fissi.**

MA c'è una zona grigia usata da molti sviluppatori indie:

### La strategia usata da molte startup

Se la tua **attività prevalente** è lo **sviluppo continuo** del software:
- Tu passi l'80-90% del tempo a sviluppare NUR
- Aggiorni features, migliori l'AI, correggi bug
- L'abbonamento è una **"licenza d'uso"** del software che sviluppi

In questo caso, molti usano **62.01.02** (sviluppo software) perché:
- L'attività prevalente è sviluppare, non "fornire hosting"
- Il cliente paga per usare il software che TU sviluppi
- Non sei un puro "hosting provider"

### ⚡ Le 3 opzioni

| Opzione | Pro | Contro | Rischio |
|---------|-----|--------|---------|
| **A) 62.01.02** (Sviluppo AI) | Zero contributi fissi, paghi solo se guadagni | Zona grigia se fai SOLO abbonamenti | Se AdE contesta, devi regolarizzare |
| **B) 63.10.10** (SaaS/Hosting) | 100% sicuro legalmente | €4.500/anno FISSI anche con €0 fatturato | Morte finanziaria per startup |
| **C) Prima A, poi B** | Parti leggero, regolarizzi quando cresci | Devi monitorare | Basso se cresci gradualmente |

## 💰 QUANTO PAGHI (se usi 62.01.02)

### Regime Forfettario — Aliquota 5% (primi 5 anni)

| Voce | Dettaglio |
|------|-----------|
| Imposta | **5%** (primi 5 anni), poi 15% |
| Coefficiente | 67% (paghi tasse sul 67% del fatturato) |
| INPS | Gestione Separata 26,07% |
| Contributi fissi | **€0** |

### Esempio concreto

**Fatturato €20.000/anno:**

```
Reddito imponibile: €20.000 × 67% = €13.400
Contributi INPS: €13.400 × 26,07% = €3.493
Base per imposta: €13.400 - €3.493 = €9.907
Imposta 5%: €9.907 × 5% = €495

TOTALE DA PAGARE: €3.988
NETTO IN TASCA: ~€16.000
```

## ❓ FAQ

### Devo aprire P.IVA subito?
**No.** Apri quando hai il primo cliente pagante.

### Posso usare 62.01.02 se vendo solo abbonamenti?
**Zona grigia.** Molti lo fanno se sviluppano attivamente il software. Conferma con commercialista.

### Cosa succede se l'AdE contesta?
Dovrai passare a commerciante e pagare la differenza contributi + sanzioni. Per questo è importante confermare PRIMA.

Online: €250-400/anno. Vale la pena per evitare errori.
